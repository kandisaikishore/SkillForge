# Development, Learning-Progress, and QA Guide

SkillForge is a skills-development project. The current source and manifests define which learning paths, practice activities, and progress-tracking features are implemented.

## Setup

```bash
git clone https://github.com/kandisaikishore/SkillForge.git
cd SkillForge
```

Use the declared runtime, dependency manager, and scripts. Keep credentials and personal learner records out of version control.

## Learning workflow tests

For implemented workflows, test:
- Creating and editing a learning goal or path
- Empty, malformed, duplicated, and unknown skill identifiers
- Marking an activity complete and undoing completion if supported
- Refresh/restart behavior at the documented persistence boundary
- Repeated completion actions and progress totals
- Empty/error states and keyboard-accessible navigation

## Progress integrity

Define how progress is calculated from activities and milestones. Identical input state should produce deterministic progress. Repeating a completion event must not inflate totals, and invalid saved state should be handled with a recoverable message rather than crashing or silently resetting progress.

## Recommendation quality

If recommendations are generated by AI or rules, document their inputs and assumptions. Validate output before displaying it and do not claim that a learning plan guarantees a job or certification.

## Pull-request checklist

- [ ] Add tests for progress calculation and repeated actions.
- [ ] Run the declared test/build commands.
- [ ] Verify refresh/restart behavior against the actual persistence layer.
- [ ] Use synthetic learner data in tests.
- [ ] State any unavailable checks.
